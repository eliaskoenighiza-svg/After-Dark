Einschränkung der Kontrolle
- npm install konnte in der isolierten Build-Umgebung wegen Netzwerk-Timeout nicht fertig ausgeführt werden.
- Deshalb konnte hier kein echter Android-Emulator-Build gestartet werden.
- Auf dem eigenen PC bitte npm install und anschließend npm run android ausführen. README.md enthält die Schritte.

Architektur-Hinweis
- Crew-/Chat-"shared"-Daten sind in dieser Emulator-Version noch lokal simuliert.
- Für echte Synchronisierung zwischen mehreren Handys muss später der Shared-Storage-Adapter an ein Online-Backend angebunden werden.
- Der Anthropic-Key liegt absichtlich nur im lokalen Proxy auf dem PC, nicht in der Android-App.
